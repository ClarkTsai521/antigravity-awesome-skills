Skills Index Explorer

從 skills_index.json 即時載入，支援搜尋與篩選，幫你快速找到需要的 skill name。

如何在專案使用 Skills

Codex CLI

將需要的 skill 資料夾複製到專案根目錄。

.codex/skills/<skill-folder>/SKILL.md

Claude Code

支援兩種常見路徑，擇一使用。

.claude/skills/<skill-folder>/SKILL.md

Cursor

多數情況可放在通用路徑。

.agent/skills/<skill-folder>/SKILL.md

Gemini CLI

使用官方建議的資料夾結構。

.gemini/skills/<skill-folder>/SKILL.md
